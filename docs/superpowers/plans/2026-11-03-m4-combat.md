## Locked interfaces and state

### Definitions

`CombatDefinitions.profile(kind: String) -> Dictionary`: fresh `{max_hp:int, armor:String, weapon:String}`; unknown `{}`. IDs `human/tank/dozer/humvee/structure/chinook`; weapon `rifle/cannon/""`. All profile HP values in design multiplied1000. Noncombatants have empty weapon.

`CombatDefinitions.weapon(kind: String) -> Dictionary`: fresh `{damage:int, damage_type:String, range:float, delay_ticks:int, clip_size:int, reload_ticks:int}`. Rifle `{5000,"small_arms",4.0,3,3,21}`; cannon `{60000,"armor_piercing",6.0,60,0,0}`. Unknown `{}`. `armor_percent(armor: String, damage_type: String) -> int`: two-column matrix in design; unknown input returns0 (reject unknown definitions in spawning, not invulnerable fallback).

Economy definitions append infantry `{cost:225,ticks:150,speed:0.8,air:false,producer:"barracks"}` and tank `{900,300,1.2,false,"factory"}` using existing named keys; barracks `{cost:600,ticks:300,power:0,footprint:Vector2i(2,2),prerequisite:"",produces:"infantry"}`. Keep factory `produces:"vehicle"` for BaseMain and existing tests; validator already accepts producer via `unit.producer`. SkirmishMain selects tank through hook. No global replacement of `vehicle`.

### Snapshot additions

- Every unit/building: `hp:int` and `max_hp:int` in milliHP. Sources have neither.
- Armed unit: `combat:{mode:String,target_id:null|int,goal:null|[float,float],next_fire_tick:int,shots_left:int,repath_tick:int}`; unarmed `combat:null`. Initial guard/null/null/0/clip_size/0; cannon shots_left0 means unlimited.
- Movement `order`, `route`, `destination`, `status` retain existing shapes. Combat intent is separate; derived chase routes remain `order:{type:"move",target:[x,y]}` so existing view/navigation assumptions survive. Never put attack target ID in `order.target`.
- Root `combat_events:Array` last tick only, shot records `{type:"shot",tick,attacker_id,target_id,damage}` sorted attacker ID, followed by death records `{type:"death",tick,object_id}` sorted victim ID. Damage records store pre-overkill armor-adjusted milliHP. Clear before each active tick. No persistent event history.
- Root `match:null|{players:[int,int],status:String,winner:null|int,ended_tick:null|int}`. Status ongoing/won/draw; player-relative defeat is presentation. Freeze after terminal step (including tick/events), reject new commands unchanged. Scenario removal remains test/setup API; not player cheat.
- Copy all nested combat/goal/events/match records in `snapshot`; update exact expected snapshots, never omit new fields from equality/hash.

`Simulation.start_match(players: Array[int]) -> Dictionary`: exactly two distinct positive registered players, both currently have builder or completed producer, match currently null; sort IDs; returns existing `{ok,error}` and mutates only match on success. No start on empty/eliminated world. Match disabled elsewhere by null.

### Commands and helper surface

Add `attack` with `entity_ids:Array[int],target_id:int`; `attack_move` with `entity_ids:Array[int],target:[number,number]`. Mixed infantry/tank groups are legal. Require all owned members armed, target enemy live ground unit or building for attack; no source/friendly/air target. Attack-move finite in-bounds walkable destination on issue; due navigation changes follow move blocked semantics. Match terminal rejects all commands. Preserve surplus-field normalization policy. Both produce ordinary due command results. Require no economy registration for combat in fixture/movement-only worlds, like move/stop.

Extend `_payload_fields`, `_validate`, `_apply_orders`, `_detach_task`, `_stop_unit`, `step`, `spawn`, `snapshot`, `remove_object`. New attack/attack_move participate in final-successful-intent coalescing. `move` changes armed mode to move; stop to guard; attack to attack; attack_move to attack_move. Never reset ammo/next_fire on intent changes. A rejected due attack does not supersede a valid earlier move.

Combat static API, using existing helper convention `sim: RefCounted`:

- `valid_target(sim, owner:int, target_id:int) -> bool`.
- `distance_squared(position:Vector2, target:Dictionary) -> float`: unit center or nearest footprint point; Definitions supplies building size.
- `plan(sim, unit_ids:Array[int]) -> void`: acquire/retain targets and request/stop movement before work phase.
- `fire(sim, unit_ids:Array[int], moved_ids:Array[int]) -> void`: current positions, ready stationary captured units; collect shots first, sum damage, apply/remove in ID order.
- `object_removed(sim, id:int) -> void`: clear references; explicit attackers guard; attack-move keeps goal to resume next tick. Called by shared removal for scenario and lethal removal.

Filter armed units before target scans; unarmed M2 benchmark worlds do not perform all-pairs targeting. Keep tiny internal helpers in combat.gd for target lookup, acquisition and pursuit. Do not create targeting/weapon/event subclasses. `_stop_unit` remains movement-only; callers manage combat mode deliberately, avoiding accidental timer reset during automatic halt.
