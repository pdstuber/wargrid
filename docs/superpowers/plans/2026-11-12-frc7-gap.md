## Review Focus

- Transplanted start whose `spawn` returns -1 (occupied cell): the row must fail, never run with fewer than 7 workers (Task 1 test).
- A leg or gap cut by the window edge or by a unit's first sighting: dropped, not truncated (Task 2 test).
- A phase the recorder does not name (`none`, `idle`, a model's own name) inside a leg: counted as `other`, and leg total = sum of its parts (Task 2 test).
- Two `loading` units on one tick: counted as `overlaps`, never folded into gaps (Task 2 test).
- Zero Hour lock holder not in `collector_ids`, or a missing frame: the holder still ends a gap; a missing frame holds the last sample (Task 3 self-test).

**Interfaces:**
- Consumes: Task 1's `probe_models()`; `ViewRows` columns `id`, `kind`/`kinds`, `phase`/`phases`, `status` (`ViewRows.STATUSES`), `x`, `y`.
- Produces (`dock_probe.gd`):
  - `static func units_of(view: Dictionary, kind: String) -> Dictionary`: id → `{"phase": String, "status": String, "position": Vector2}`; `"none"` for `NONE` phase, `"other"` for status 255.
  - `func observe(tick: int, units: Dictionary) -> void`: call once per tick inside the window only.
  - `func summary() -> Dictionary`: `samples`, `idle_samples` (ticks with no `loading` unit), `gaps: Array[int]`, `contended: Array[int]`, `ready: Array[int]`, `overlaps: int`, `legs_empty: Array[Dictionary]`, `legs_loaded: Array[Dictionary]`, `drops: int`, `drops_blocked: int`, `cycles: Array[int]`, `trips: int`. Leg keys: `total`, `flying`, `standing`, `other`, `moved`, `path_pending`.
  - `static func quantile(values: Array, q: float) -> float` (nearest rank; 0.5 = median; empty → -1.0).
  - `static func line(model: String, scenario: String, summary: Dictionary) -> String`.

Definitions (the same on the Zero Hour side, Task 3):
- Pile holder = unit in `loading`. Gap = number of consecutive samples with no holder between two holders (0 for a direct handoff). `contended`: at the last holder sample another unit was in `lead_source` or `waiting_source`; `ready`: one was in `waiting_source`.
- Empty leg: first tick after `unloading` until the tick before `loading`; loaded leg: after `loading` until before `unloading`. Parts: `flying` (`flying_*`), `standing` (`lead_*`, `waiting_*`), `other` (anything else); `moved` = ticks whose position differs from the previous tick; `path_pending` = ticks with that status.
- Drop: `flying_*` on one tick, `seeking` or `idle` on the next; `drops_blocked` = drops whose unit had status `blocked` on either tick.
- Cycle: ticks between one unit's successive `unloading` starts; trips = `unloading` starts.
