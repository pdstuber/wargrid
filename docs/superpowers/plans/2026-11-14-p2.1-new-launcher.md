# P2.1 New launcher Implementation Plan

**Status:** approved by the user 2026-11-14 (subagent-driven run, Sonnet implementers, attended, started the same day).

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Run rules: [milestone prompt](../../milestone-prompt.md).

**Goal:** Replace the one-column launcher with the minimal sidebar launcher (Play, Join, Settings, Credits, a Waiting view), remembered picks, a desktop Fullscreen switch and no black bars around the launcher.

**Architecture:** One scene, `game/scenes/launcher.tscn`: a sidebar plus a content area with five sibling page containers, one visible at a time. `launcher.gd` keeps connection, link and start logic and gains page switching and the busy lock. Remembered picks and fullscreen live in a new static `launcher_settings.gd` (section `[launcher]` of `AudioSettings.path`, the pattern of `playtest_settings.gd`). One `Theme` resource styles the grey look.

**Tech Stack:** Godot 4.7.2 stable, typed GDScript, suite runner `game/tests/run_tests.gd`.

**Spec:** [P2.1 design](../specs/2026-11-14-p2.1-new-launcher-design.md) (read fully once; every decision is settled). Mockups `docs/images/launcher-mockups/minimal-*.webp`. Verification file: `docs/reference/p2.1-verification.md` (Task 1 creates it with the resume record).

## Review Focus

1. **Back to menu after a match:** the launcher is instantiated again by `change_scene_to_file`; remembered picks must show, `code_applied` must keep a stale `?code=` from reopening Join, and `expand` must be set again. Test in Task 4 (L13).
2. **Settings file shared with audio and playtest:** saving launcher picks must not drop `[audio]` or `[playtest]` keys. Test in Task 1 (L3).
3. **A corrupt or hand-edited `settings.cfg`** (wrong types, e.g. `faction = 3`): per-field fallback, no crash. Test in Task 1 (L2).
4. **Leaving the launcher by any path restores `keep`:** offline start, online start, test `free()`. Test in Task 2 (L7).
5. **Relay drops between Create and welcome** (Connecting, not yet Waiting): sidebar unlocks, Play footer shows the reason. Test in Task 4 (L11).
